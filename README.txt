ARASH DEV — نسخه دارای پنل مدیریت نمونه‌کارها

داخل پوشه:
index.html = سایت عمومی
admin.html = پنل خصوصی مدیریت
config.js = تنظیمات اتصال
schema.sql = ساخت جدول و فضای عکس‌ها

مهم: کدها آماده‌اند اما برای فعال شدن افزودن/ویرایش/حذف آنلاین، یک بار اتصال رایگان Supabase لازم است.

۱) در https://supabase.com حساب بساز و پروژه جدید ایجاد کن.
۲) از Project Settings > API، مقدار Project URL و کلید anon/publishable را بردار.
۳) فایل config.js را باز کن و دو مقدار YOUR_SUPABASE_PROJECT_URL و YOUR_SUPABASE_ANON_KEY را جایگزین کن. کلید service_role را هرگز در سایت نگذار.
۴) در Supabase > SQL Editor محتوای schema.sql را کامل اجرا کن.
۵) در Authentication > Users یک کاربر با ایمیل و رمز خودت بساز؛ این حساب ورود خصوصی پنل است.
۶) تمام فایل‌های این پوشه را در یک مخزن GitHub آپلود کن. Settings > Pages > Deploy from a branch، شاخه main و پوشه /(root) را انتخاب و Save کن.
۷) لینک عمومی GitHub Pages را در بیوی اینستاگرام بگذار. پنل مدیریت در همان آدرس با /admin.html باز می‌شود.

استفاده:
- وارد /admin.html شو و با حساب مدیر وارد شو.
- نام، دسته‌بندی، توضیح و عکس کاور را ثبت کن؛ چند عکس گالری هم قابل انتخاب است.
- انتشار عمومی را روشن بگذار تا همه بازدیدکنندگان پروژه را ببینند.
- از فهرست، امکان ویرایش و حذف وجود دارد.
